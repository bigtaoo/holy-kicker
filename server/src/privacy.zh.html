隐私政策

更新日期：2026-10-09  ·  蹴鞠僧（Holy Kicker）  ·  support@gamestao.com  ·  English

本政策说明游戏《蹴鞠僧》收集哪些数据、为什么收集，以及你可以怎么做。无论你在我们自己的网站、CrazyGames 等游戏平台还是 iPhone 应用里玩，本政策都适用。我们遵守欧盟《通用数据保护条例》（GDPR）及适用的数据保护法律。如中英文版本有出入，以英文版为准。

游戏没有账号，也不需要注册。你的进度和设置保存在你的设备上（在 CrazyGames 上则保存在平台自己的存档里）。游戏只向我们自己的服务器发送两类数据：游戏统计和排行榜成绩，它们关联的是一个随机的游戏 ID，而不是你的身份。 在欧洲经济区、英国和瑞士，你同意之前不会发送任何数据。其他地区默认发送，你可以随时关闭：设置 → 游戏数据 → 数据共享。

1. 责任人

数据控制者是 Tao Wang，德国的个体经营者（非公司），联系方式：support@gamestao.com。

2. 我们收集什么

类别具体内容用途法律依据
游戏统计 一份固定的事件清单：游戏启动（已玩局数、武僧等级）、一局开始和结束（章节、模式、武僧、法器、到达的波次、时长、等级、击败的敌人数、胜负或放弃）、完成新手引导、用游戏内货币购买、领取游戏内奖励、观看可选广告、在 iPhone 应用里购买或恢复购买（哪件商品、是否成功，绝不含任何支付信息）、分享游戏、游戏切到后台（当时在哪个界面、在屏幕上停留了多久）。每条附带随机游戏 ID（见第 4 节）、本次启动的随机 ID、平台、游戏版本和语言。事件清单和字段都写死在游戏代码里，服务器拒收其他任何内容。 了解玩家玩了哪些部分、在哪里停下、是否回来，用于平衡和改进游戏 欧洲经济区、英国、瑞士：你的同意（GDPR 第 6(1)(a) 条；设备上保存 ID 依据德国 TDDDG 第 25(1) 条）。其他地区：我们改进游戏的正当利益（第 6(1)(f) 条）
排行榜 你在每个章节榜上的最好成绩（字段同上），以及榜上显示的名字：如果你登录了 CrazyGames，就是你的 CrazyGames 用户名；在 iPhone 应用里，如果你登录了 Game Center，就是你的 Game Center 昵称；否则是游戏随机生成的名字（两个词加一个数字）。榜上显示这个名字和一个由游戏 ID 经密钥计算出的短标签，从不显示游戏 ID 本身。CrazyGames 上的游客不上榜。 运行公开排行榜 同游戏统计
问题报告 仅当你点“报告问题”并发送时：你写的内容、设备描述（浏览器的 User-Agent 或手机型号和系统）、语言、游戏 ID、你在游戏中的位置，以及这一局操作的回放。 查找和修复 bug 你发送报告即表示同意（第 6(1)(a) 条）
连接数据 你的 IP 地址，只在内存中用于限制单个地址的请求频率，不会保存。 防止服务器被滥用 正当利益（第 6(1)(f) 条）

3. 我们不收集什么

  • 没有邮箱、密码和账号。
  • 没有第三方统计或追踪。上述统计只发到我们自己的服务器。游戏本身不含 Google Analytics、Firebase 或任何追踪脚本。iPhone 应用内含 Google 的广告软件，用于第 5 节所述的广告，且只投放非个性化广告。
  • 没有广告 ID，不建立你的画像，也不跨网站或应用追踪你。iPhone 应用从不请求追踪你，所以我们和 Google 都拿不到 Apple 的广告标识符。
  • 不收集位置。CrazyGames 会告诉游戏你所在的国家，游戏只在你的设备上用它决定发送前是否要先征求同意，不会发给我们。在 iPhone 应用里，Google 可能根据你的 IP 地址估算大致位置来投放广告（见第 5 节）。
  • 不收集支付信息。唯一需要真钱购买的是 iPhone 应用里的去广告卡，通过 Apple 的 App Store 购买。付款由 Apple 处理，我们看不到你的银行卡、Apple ID 或姓名。
  • 不出售或提供你的数据给任何人用于其他目的。

4. 保存在你设备上的内容

游戏在浏览器的本地存储里保存几项内容（在 CrazyGames 上保存在平台存档里，登录的玩家换设备也能继续；在 iPhone 应用里还会复制一份到应用自己的存储，即使 iOS 清掉网页存储也不会丢）。不使用 Cookie。

  • hk.save：你的进度
  • hk.settings：你的设置，包括你对游戏数据的选择
  • hk.run：未打完的一局，方便你继续
  • hk.install：随机游戏 ID。只有在第一次发送数据时才会生成，所以如果你从不允许共享，它就不存在。可以在设置 → 游戏数据中看到。
  • hk.named：上次发送的排行榜名字，避免重复发送
  • hk.adFree（仅 iPhone 应用）：你是否拥有去广告卡，以 App Store 最近一次告诉应用的为准

5. 广告

在我们自己的网站上游戏没有广告。在 CrazyGames 上，广告由 CrazyGames 投放：可选的激励视频、两局之间的短插屏广告和大厅里的横幅。这些广告及其所需的同意由 CrazyGames 的隐私政策管理。我们不会从中得到广告 ID 或任何关于你的信息，只知道广告是否播完。

在 iPhone 应用里，广告由 Google AdMob 投放：可选的激励视频和两局之间的短插屏广告。每次请求都只要非个性化广告，应用也从不弹出 Apple 的追踪授权框。在欧洲经济区、英国和瑞士，Google 的同意表单会先征求你的意见，设置 → 游戏数据 → 广告隐私可以再次打开它。为了投放、统计和防范滥用，Google 会处理你的 IP 地址、一个只在同一开发者的应用之间共享的标识符、你看过哪些广告以及是否点击，还有其广告软件的技术和崩溃数据，详见 Google 如何使用来自使用其服务的应用的信息。拥有去广告卡后不再展示任何广告，奖励直接到账。

6. 还有谁处理这些数据

  • 你所在的游戏平台（例如 CrazyGames）：托管页面、保存进度、在你登录时告诉游戏你的用户名、投放广告：CrazyGames 隐私政策。
  • Apple（iPhone 应用）：App Store、去广告卡的购买，以及 Game Center（你登录后它会把你的昵称告诉游戏）：Apple 隐私政策。
  • Google（iPhone 应用）：广告（见第 5 节）：Google 隐私政策。
  • Cloudflare：分发游戏，并把流量转到我们的服务器。
  • Hetzner Online（德国）：运行我们的服务器。
  • MongoDB Atlas：托管数据库。

它们根据数据处理协议为我们处理数据。如有在欧洲经济区以外处理的情况，均依据欧盟委员会的标准合同条款。

7. 保存多久

  • 游戏事件：90 天，之后由数据库自动删除。
  • 问题报告：180 天，之后删除。
  • 排行榜成绩、榜上名字和每个游戏 ID 的一条汇总（首次游玩日期、之后游玩的日期、平台、首个游戏版本、每章首次通关用了几天几局）：保留到排行榜停止运行，或你要求删除为止。

8. 你的权利

你可以要求查阅、更正、删除、限制处理你的数据，获取可携带的副本，或反对处理。凡是基于同意的处理，你都可以随时撤回，和同意一样简单：设置 → 游戏数据 → 数据共享：关会立即停止所有发送，尚未发出的事件会被丢弃。

因为我们不知道你是谁，只能通过游戏 ID 找到你的数据。如需查看或删除，请把设置中显示的游戏 ID 发到 support@gamestao.com。我们会在 30 天内免费答复。你也有权向数据保护机构投诉。

9. 儿童

游戏不向任何人索取个人数据：没有账号、没有聊天，除了可选的问题报告外没有任何需要输入文字的地方。如果你认为有儿童在报告中发送了个人数据，请联系我们，我们会删除。

10. 变更

我们可能会更新本政策，页首的日期始终对应当前版本。

11. 联系方式

任何隐私问题或请求：support@gamestao.com。
